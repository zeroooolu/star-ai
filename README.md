# 星球发行｜自助音乐发行

星球发行独立产品仓库，由 `kanjian-distribution-products` 母仓拆分。

## 当前产品基线

本仓库只保留一份有效产品文档：

- [`PRODUCT.md`](./PRODUCT.md) — 产品定位、商业模式、定价、发行额度、渠道策略、AI / Channel Eligibility、单位经济、UX 与 MVP 验收口径。

核心商业模式：

> **1 首歌曲 × 1 个发行渠道 × 1 次发行交付 = 1 次发行额度 = ¥1。**

产品支持普通音乐、AI 辅助和 AI 生成音乐；AI 只作为权利、披露、渠道资格和风控属性，不形成独立产品版本或价格。

## 原型

- `/`：产品首页
- `/platforms`：支持平台与发行规则
- `/pricing`：价格与发行额度
- `/release`：新建发行
- `/app`：产品工作台

跨产品总体架构、共享发行底座与跨产品决策继续维护在 `kanjian-distribution-products` 母仓。
